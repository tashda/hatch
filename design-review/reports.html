Reports

Where model work goes: by provider and model, by task, by area and by ticket, over time. The Usage page in Settings stays short (today, this week, a warning); Reports is the place to look closer. A plan first: the data it needs, what it shows, and the decisions for you.

What Hatch records first

Today each run records its ticket, the agent's name, a step, tokens in and out, start, end and outcome. It does not record which provider and model ran, or cache tokens and cost, which programs report. A database change adds, per run: provider, model, task, cache tokens, and the cost the program reports (Claude Code reports one per run). Runs before the change show as "Unknown provider".

Cost: API providers bill per token, so a known price list (per model, editable) turns tokens into money. Subscriptions (Claude plan, ChatGPT plan) have no per-token price; they show tokens and share of the week instead of money.
